# Atv - CI com GitHub Actions
## Tecnologias 
* Python
* Pytest
* GitHub Actions

## Funcionalidades

O projeto é uma calculadora simples

* Soma
* Subtração
* Multiplicação
* Divisão

## Testes unitários

Foram implementados testes unitários utilizando o Pytest.

Para rodar os testes

```bash
python -m pytest -v
```

## Build

Para gerar a build

```bash
python -m build
```
